# Support

Use GitHub Issues for reproducible verifier defects, documentation problems, conformance/evidence questions, and bounded feature proposals. Include the affected version/revision, expected and observed behaviour, and the smallest useful fixture or evidence reference.

Security vulnerabilities must follow [`SECURITY.md`](SECURITY.md) and must not be disclosed publicly before remediation.

This repository owns its reference-verifier implementation and associated evidence surfaces. CAWG/C2PA and TRQP semantic/conformance/assurance authorities remain where explicitly declared; repository-local implementation results do not transfer those authorities.
